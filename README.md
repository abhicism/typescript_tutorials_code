# TypeScript Tutorials

A collection of TypeScript code examples and tutorials for learning TypeScript concepts.

## 📚 Topics Covered

- Basics (variables, types, functions)
- Interfaces & Types
- Classes & OOP concepts
- Generics
- Advanced Types
- Modules & Namespaces

## 🛠️ Setup

```bash
git clone https://github.com/abhicism/typescript_tutorials_code.git
cd typescript_tutorials_code
npm install
```

## ▶️ Running the code

```bash
npx ts-node filename.ts
```
